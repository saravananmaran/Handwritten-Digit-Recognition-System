WHY TEST SET MUST REMAIN SEPARATE:
=================================================================
In rigorous Machine Learning methodology, the test dataset must remain strictly separated and untouched throughout all training and hyperparameter tuning phases. While the training set optimizes network weights via gradient descent and the validation set guides architectural choices and early stopping, the test set serves as an unbiased proxy for real-world unseen data. Exposing test data during training causes data leakage, leading to over-optimistic metric estimates that fail during real-world inference.
